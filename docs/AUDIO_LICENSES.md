# Block Workshop audio credits and licenses

The production audio files are stored in `public/audio/`. Their recorded
provenance comes from the [Cozy Gallery audio register](https://github.com/whil3true/pairs_and_paths/blob/dev/docs/AUDIO_LICENSES.md).
All seven files are documented under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

| File | Use in Block Workshop | Creator and source |
| --- | --- | --- |
| `forget_me_not_in_f_major_looped.ogg` | Looping soundtrack | Kistol, [Forget Me Not](https://opengameart.org/content/forget-me-not) |
| `click_003.ogg` | UI and chapter selection | Kenney, [Interface Sounds](https://kenney.nl/assets/interface-sounds) |
| `drop_003.ogg` | Piece pickup | Kenney, [Interface Sounds](https://kenney.nl/assets/interface-sounds) |
| `drop_002.ogg` | Piece placement | Kenney, [Interface Sounds](https://kenney.nl/assets/interface-sounds) |
| `drop_004.ogg` | Line clears and combos | Kenney, [Interface Sounds](https://kenney.nl/assets/interface-sounds) |
| `bong_001.ogg` | Invalid action and defeat | Kenney, [Interface Sounds](https://kenney.nl/assets/interface-sounds) |
| `jingles_PIZZI10.ogg` | Order completion | Kenney, [Music Jingles](https://kenney.nl/assets/music-jingles) |

The SHA-256 values of all six effects match the Cozy Gallery register. That
register verified the Interface Sounds files against a published mirror and
the Music Jingles file against the SHA-256 and size in a published Git LFS
pointer. Its source links and file-level evidence are recorded in the
[effects verification section](https://github.com/whil3true/pairs_and_paths/blob/dev/docs/AUDIO_LICENSES.md#effects-kenney-pack-verification-2026-10-31).
The official pack downloads were outside that verification. The register
documents Kistol's source and its CC0 declaration without a donor hash for
the soundtrack. [Local production checksums](assets.sha256.json) cover all
seven Block Workshop files.
